Planned official clients for the [server](https://github.com/corvin-chess/server) public HTTP and WebSocket API, in TypeScript and Python, for tools and [bots](https://github.com/corvin-chess/bots) that need a stable Corvin surface. Docs and OpenAPI bindings will follow [website](https://github.com/corvin-chess/website) once published. No TypeScript or Python client packages are in this repository yet. Everything chess-specific stays Corvin-original; clients speak the public API only.
